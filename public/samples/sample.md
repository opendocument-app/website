# A sample Markdown file

Opened in your browser by **OpenDocument Reader** — nothing was uploaded.

Markdown is plain text with a convention on top, so a `.md` file carries no
signature. The demo asks the engine for it *by name*, and the engine renders
the prose: headings, emphasis, lists, links and tables.

## What survives

- **Bold** and *italic* text
- `inline code` and fenced blocks
- [Links](https://opendocument.app), drawn but not followed here
- Tables:

| Application | Open format | Also opens      |
|-------------|-------------|-----------------|
| Writer      | ODT         | DOC, DOCX, RTF  |
| Calc        | ODS         | XLS, XLSX, CSV  |
| Impress     | ODP         | PPT, PPTX       |

```
No pen for this one: a rendered Markdown file is read, not written.
```

Now drop a Markdown file of your own onto the page.
